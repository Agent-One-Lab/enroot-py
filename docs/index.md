# enroot-py

`enroot-py` is a small Python client for working with [Enroot](https://github.com/NVIDIA/enroot) containers via the `enroot` CLI.

!!! warning
    This documentation is automatically generated and maintained with AI assistance.
    Please verify critical production behavior against the source code and tests.

## What it supports

- Pull and import images via `enroot import`
- Create and start containers
- Run commands inside running containers (`exec_run`) with optional host-side timeouts
- Stop / kill / remove containers
- Async variants for starting/executing operations
